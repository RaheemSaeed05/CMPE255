# NYC Taxi Trip Prediction

This project reproduces an end-to-end data science experiment based on the NYC Taxi Trip Duration challenge.

## Objective

Predict taxi trip duration using supervised regression.

## Methodology

The project follows the CRISP-DM methodology and includes:

- Business Understanding
- Data Understanding
- Exploratory Data Analysis
- Data Cleaning
- Feature Engineering
- Model Training
- Model Evaluation
- Final Recommendation

## Models

- Baseline Model
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Metrics

- MAE
- RMSE
- R²
